# SurgiTag 6축 힘 센서 — 캘리브레이션 정확도 보고서

- **작성일**: 2026-06-30
- **대상**: 6축 힘/토크 센서 (굽힘 4축 + 그리핑 + 비틀림)
- **요약**: 캘리브레이션 후 6축 모두 가한 힘을 실제 단위(N, N·m)로 복원하며, 굽힘·비틀림은 거의 오차 없이 일치한다.

---

## 1. 측정하는 6개의 값

| force | 의미 | 단위 |
|-------|------|------|
| bending_gripper_x | 그리퍼 쪽 x평면 굽힘력 | N |
| bending_trocar_x | 트로카 쪽 x평면 굽힘력 | N |
| bending_gripper_y | 그리퍼 쪽 y평면 굽힘력 | N |
| bending_trocar_y | 트로카 쪽 y평면 굽힘력 | N |
| gripping | 집게가 무는 힘 | N |
| torsion | 축 비틀림 토크 | N·m |

- gripper / trocar 굽힘은 같은 평면의 굽힘을 두 지점에서 잰 값이라 둘 다 같은 크기를 읽는다(설계상 동일값).
- 출력값은 전압 원신호가 아니라 **실제 물리 단위로 보정된 힘**이다. 예: 화면에 `4.9`가 뜨면 4.9 N 이 가해지고 있다는 뜻.

---

## 2. 캘리브레이션 후 정확도

각 축에 알고 있는 힘을 가했을 때, 보정된 출력이 그 값을 얼마나 정확히 복원하는지.

| force | R² | RMSE (평균 오차) | 검증 범위 |
|-------|----|------|------|
| bending_gripper_x | 1.000 | **0.087 N** | −4.9 … +4.9 N |
| bending_trocar_x | 1.000 | **0.090 N** | −4.9 … +4.9 N |
| bending_gripper_y | 1.000 | **0.061 N** | −4.9 … +4.9 N |
| bending_trocar_y | 0.999 | **0.106 N** | −4.9 … +4.9 N |
| gripping | 0.979 | **0.537 N** | 0 … +9.8 N |
| torsion | 0.997 | **0.010 N·m** | −0.23 … +0.23 N·m |

- **R²**: 1.0 에 가까울수록 출력이 가한 힘과 선형으로 완벽히 비례. 굽힘 4축은 1.000, 비틀림 0.997 로 사실상 직선 일치.
- **RMSE**: 출력이 정답값에서 평균적으로 벗어나는 양 = 측정 오차. 굽힘은 ±0.1 N 안쪽, 비틀림은 ±0.01 N·m 안쪽.

---

## 3. 축 분리(디커플링) 정확도 — 한 축에만 힘을 줬을 때 6축 출력

| 가한 힘 | grip_x | troc_x | grip_y | troc_y | gripping | torsion |
|---------|-------|-------|-------|-------|----------|---------|
| **굽힘 x** +4.9 N | **+4.92** | **+4.96** | +0.24 | +0.21 | −1.07 | −0.00 |
| **굽힘 y** +4.9 N | +0.17 | +0.17 | **+4.88** | **+4.86** | −1.20 | −0.00 |
| **그리핑** +9.8 N | +0.04 | +0.06 | −0.01 | +0.03 | **+10.00** | +0.01 |
| **비틀림** +0.23 N·m | +0.12 | −0.24 | −0.30 | +0.16 | −1.57 | **+0.23** |

- **굽힘**: 가한 평면의 두 출력이 full 값(≈4.9 N)으로 같이 나오고, 다른 평면으로 새는 양은 ~0.2 N(약 5%) 수준.
- **그리핑**: 9.8 N → **10.0 N**, 다른 축으로 새는 양 <0.1 N 으로 거의 완벽히 분리.
- **비틀림**: 0.23 → 0.23, 토크를 정확히 복원.

---

## 4. 얼마나 미세한 힘까지 잡을 수 있나

측정 오차(RMSE)와 노이즈 바닥이 그대로 분해능 한계가 된다. 100 Hz 블록평균(빠른 DAQ 오버샘플 활용)으로 노이즈를 ~3.2× 낮춘 상태 기준.

| 축 | 실용 분해능 (잡을 수 있는 최소 변화) | 풀스케일 대비 |
|----|------|------|
| 굽힘 4축 | **약 0.1 N** | 4.9 N 중 ~2% |
| 비틀림 | **약 0.01 N·m** | 0.23 N·m 중 ~4% |
| 그리핑 | **약 0.5 N** | 9.8 N 중 ~5% |

- 굽힘은 0.1 N 안팎의 미세한 힘 변화까지 구분 가능 — 손가락으로 살짝 누르는 정도의 힘 변화도 그래프에서 또렷이 읽힌다.
- 비틀림은 0.01 N·m 단위의 작은 토크 변화를 잡는다.
- 그리핑은 분해능이 가장 거칠어(~0.5 N) 무는 힘의 대략적 크기를 보는 데 적합하다.

## 5. 보정식·디커플링 행렬·전압 (구체값)

앞의 정확도는 아래 **아핀(affine) 보정식** 하나로 얻는다. 입력은 브리지 원신호
**전압**, 출력은 실제 단위 힘이다.

### 5.1 입력 — 원신호 전압 벡터

NI USB-6009 의 6개 아날로그 입력이 읽는 half/quarter-bridge 증폭 출력전압(단위 **V**):

```
v = [ bgx, btx, bgy, bty, grip, tor ]   (단위: V)
```

| 코드 | AI | 브리지 | 전압의 의미 |
|------|----|--------|------|
| `bgx` | A0 | half | 그리퍼 쪽 x평면 굽힘 브리지 전압 |
| `btx` | A1 | half | 트로카 쪽 x평면 굽힘 브리지 전압 |
| `bgy` | A4 | half | 그리퍼 쪽 y평면 굽힘 브리지 전압 |
| `bty` | A5 | half | 트로카 쪽 y평면 굽힘 브리지 전압 |
| `grip`| A2 | quarter| 그리핑 게이지 전압 |
| `tor` | A6 | quarter| 비틀림 로제트 게이지 전압 |

### 5.2 보정식 (전압 → 힘)

```
clean(6) = Wᵀ · v + b
```

- `W` : 6×6 디커플링/스케일 행렬(계수 단위 = **N/V**, 비틀림 행만 **N·m/V**).
  물리 배선 구조(`wiring.py` 의 `ALLOWED_SIGNALS`)를 강제한 **블록 구조**라 대부분 0이다.
- `b` : 무부하 오프셋(영점), 단위는 각 힘의 단위(N, 비틀림은 N·m).
- 최소제곱으로 **160 스냅샷**(2026-06-30 두 세션)에서 적합.

### 5.3 계산된 결과 — 행렬 `Wᵀ` 와 오프셋 `b`

각 행 = 하나의 출력 힘. 값 = (해당 전압 × 계수)들의 합 + `b`. (0 = 배선상 결합 없음)

| 출력 힘 (단위) | ×`bgx` | ×`btx` | ×`bgy` | ×`bty` | ×`grip` | ×`tor` | `b` (오프셋) |
|---|---|---|---|---|---|---|---|
| `bending_gripper_x` (N) | **−8.8661** | 0 | 1.2644 | 0 | 0 | 0 | −0.1312 |
| `bending_trocar_x` (N)  | 0 | **−2.3237** | 0 | 0.3471 | 0 | 0 | −0.0068 |
| `bending_gripper_y` (N) | 1.7304 | 0 | **6.6150** | 0 | 0 | 0 | +0.1177 |
| `bending_trocar_y` (N)  | 0 | 0.7878 | 0 | **2.9513** | 0 | 0 | −0.1514 |
| `gripping` (N)          | 0 | 0 | 0 | 0 | **22.2762** | 0 | −0.6730 |
| `torsion` (N·m)         | 0.2224 | −0.1719 | 0.0699 | −0.2402 | 0 | **−1.2247** | −0.0044 |

풀어 쓴 6개 보정식:

```
bending_gripper_x =  -8.8661·bgx + 1.2644·bgy                                   - 0.1312
bending_trocar_x  =  -2.3237·btx + 0.3471·bty                                   - 0.0068
bending_gripper_y =   1.7304·bgx + 6.6150·bgy                                   + 0.1177
bending_trocar_y  =   0.7878·btx + 2.9513·bty                                   - 0.1514
gripping          =  22.2762·grip                                              - 0.6730
torsion           =   0.2224·bgx - 0.1719·btx + 0.0699·bgy - 0.2402·bty - 1.2247·tor - 0.0044
```

- **블록 구조 해석**: 그리퍼 굽힘은 그리퍼 게이지(`bgx,bgy`)만, 트로카 굽힘은 트로카
  게이지(`btx,bty`)만 참조 → 두 region 이 채널 단에서 분리. `gripping` 은 자기 채널
  1개(스케일만). `torsion` 만 굽힘 4채널까지 써서 로제트에 새는 굽힘 성분을 보정.
- 대각(굵게) = 스케일, 같은 region 내 비대각 = 잔여 x↔y 커플링 상쇄.

### 5.4 검산 예시 (원전압 → 힘)

굽힘 y 방향으로 **4.9 N** 을 가한 실제 스냅샷의 원전압:

```
v = [bgx, btx, bgy, bty, grip, tor]
  = [0.0842, 0.2365, 0.6920, 1.6236, -0.0231, -0.2977] V
```

보정식 대입:

```
bending_gripper_y = 1.7304·0.0842 + 6.6150·0.6920 + 0.1177 = 4.84 N
bending_trocar_y  = 0.7878·0.2365 + 2.9513·1.6236 - 0.1514 = 4.83 N
```

가한 4.9 N 을 앞단(그리퍼)·뒷단(트로카) 게이지가 각각 **4.84 / 4.83 N** 로 복원한다.
트로카 없는 자유 캔틸레버라 앞≈뒤(설계상 동일값)이며, 트로카가 개입하면 뒷단이
커지고 그 차이가 `F_trocar` 가 된다.

> 행렬 원본(전체 정밀도)은 [`calib.json`](calib.json) 의 `W`·`b` 필드에 있다. `calib.json`
> 의 `W` 는 (signals×axes) 로 저장되며 `clean = W.T @ v + b` — 위 표는 그 `Wᵀ` 이다.
