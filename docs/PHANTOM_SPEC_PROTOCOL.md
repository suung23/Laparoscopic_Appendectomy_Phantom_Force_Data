## 1. 센서·기구 제약 — 프로토콜을 결정하는 5가지

이 다섯 가지가 측정 방법을 거의 전부 규정한다. 설계 이유를 Methods에 그대로 쓸 수 있다.

| 제약 | 근거 | 프로토콜 결과 |
|---|---|---|
| **축방향(thrust) 채널이 없다** | 6축 = 굽힘 4 + gripping + torsion ([`wiring.py`](wiring.py)의 `WIRING`). 축방향 힘 채널이 아예 없고, half-bridge가 축방향 압축을 공통모드로 제거 | **모든 하중을 샤프트에 수직으로 가한다.** 샤프트 축방향 압입은 출력이 0에 가깝다 |
| **N 값이 모멘트암에 비례한다** | 굽힘 게이지는 모멘트를 재고, 캘리브레이션 지점의 모멘트암을 가정해 N으로 환산 ([`CDE2026/EXPERIMENT1_GUIDE.md`](CDE2026/EXPERIMENT1_GUIDE.md)) | 접촉점을 테이프로 고정해 전 세션 동일하게. **절대 N 확정은 부록 A-1** |
| **변위 채널이 없다** | [`dataset_recorder.py`](dataset_recorder.py)의 h5 스키마는 `timestamp` / `forces(6)` / `raw(6)` 뿐 | 강성(N/mm) 계열은 전부 **부록 A-2로 보류** |
| **`gripping`은 손잡이 힘이다** | 게이지 GL이 손잡이에 부착 ([`CDE2026/CDE_2026_REPORT.md`](CDE2026/CDE_2026_REPORT.md) §2.3). 분해능 0.5 N, 순수 비틀림에 −1.57 N 오염 | 파지력을 **handle actuation force**로 표기. 임계 판정은 `F_tip`으로 한다 |
| **계측 기구가 grasper 1개뿐이다** | 게이지가 부착된 복강경 툴이 grasper 하나. 절단·결찰 기구에는 게이지가 없다 | **모든 힘은 "파지 후 당기기"로만 가해진다.** 양손 대항견인(counter-traction) 불가, 절단 과제 불가. 파단 부위를 **선택할 수 없고 사후 분류**한다 (§5) |

읽어낼 값의 정의:

```
F_tip = ‖(bending_gripper_x, bending_gripper_y)‖          크기 (N)
θ     = atan2(bending_gripper_y, bending_gripper_x)        방향 (rad)
```

앞단(원위) 게이지만으로 구성되므로 트로카 반력이 섞이지 않는다. 팬텀 특성화는 기구를 트로카에 통과시키지 않으므로 `F_trocar`는 쓰지 않는다.

> **파지력은 `F_tip`에 나타나지 않는다.** jaw가 조직을 무는 힘은 jaw 내부에서 서로 반대 방향으로 작용하므로 샤프트에 알짜 횡력을 만들지 않는다. 파지는 `gripping`(손잡이) 축으로만 보이고, `F_tip`에 잡히는 것은 **비대칭 파지·조직 반작용으로 생기는 횡력**이다. 두 축을 섞어 읽지 말 것.

## 2. 측정 순서와 지금 낼 수 있는 값

**순서가 중요하다.** 비파괴 측정을 모두 끝낸 시편을 마지막에 파단시킨다. 같은 시편에서 조작 힘 → 미끄러짐 → 파단을 연속으로 얻으면 시편 간 변동이 제거되고, 소모되는 충수 개수가 1/3로 줄어든다.

```
시편 1개당:  Phase 1 (조작, 반복 가능)  →  Phase 2 (미끄러짐, 반복 가능)  →  Phase 3 (파단, 1회)
```

**Phase 2가 Phase 3의 상한을 정한다.** 기구가 grasper 하나뿐이므로 파단력은 "파지해서 당기는 힘"으로만 가해진다. 따라서 **미끄러짐 임계력보다 큰 파단력은 측정 자체가 불가능하다** — 조직이 찢어지기 전에 jaw에서 빠져나간다. Phase 2를 먼저 하는 이유가 순서 편의가 아니라 이것이다. 미끄러짐 임계력이 낮게 나오면 Phase 3은 하한값만 얻는다(§5.3).

### 2.1 지금 낼 수 있는 값 / 보류

| 스펙 | 단위 | 지금 가능? |
|---|---|---|
| 파지 개시력 | N | ✅ Phase 1 |
| 충수 거상력 | N | ✅ Phase 1 |
| 이동 중 힘 포락선·방향 분포 | N | ✅ Phase 1 |
| 미끄러짐 임계력 (젤 전/후 비) | × (무차원) | ✅ Phase 2 |
| 파단·분리력 (부위별 층화) | N | ⚠️ Phase 3 — 부위 선택 불가, 미끄러짐이 상한 |
| 최약 고리와 빈도 | 분류 | ✅ Phase 3 |
| 맹장 압입 강성 | N/mm | ⛔ 부록 A-2 (변위 부여 지그) |
| 충수 굽힘 강성 | N/mm | ⛔ 부록 A-2 |
| 이중경도 전이점 | N, mm | ⛔ 부록 A-2 |

### 2.2 절대 N에 대한 단서 — 반드시 읽을 것

현재 [`calib.json`](calib.json)은 2026-06-30 자유 캔틸레버 상황에서 적합된 것이다. 하중 지점이 그때와 다르면 **N 값이 미지의 비례 상수만큼 틀어진다** (모멘트암 차이). 외부 기준기 없이는 그 상수를 확정할 수 없다.

따라서 부록 A-1을 수행하기 전까지, 본문 Phase 1·3의 N 값은 이렇게 다룬다.

| 용도 | 유효성 |
|---|---|
| 같은 접촉점·같은 세션 내 **상대 비교·순위** | ✅ 유효 |
| **비(ratio)** 로 보고하는 값 (Phase 2 젤 효과) | ✅ 유효 — 상수가 상쇄됨 |
| 항목 간 비율 (예: 거상력 대비 파단력) | ✅ 유효 |
| 논문의 **절대 N 스펙** | ⛔ A-1 완료 후 확정 |

**실무상 대응**: 지금은 측정을 전부 돌려 두고, A-1이 끝나면 **환산 계수 하나를 곱해** 절대값으로 바꾼다. 원전압 `raw`가 h5에 함께 저장되므로 나중에 다른 행렬로 재계산할 수도 있다. 측정을 미룰 이유는 없다.

## 3. Phase 1 — 조작 힘 (비파괴)

실제 수술 동작에서 나오는 힘을 기록해 팬텀 스펙으로 만든다. 파괴가 없으므로 같은 시편에서 반복할 수 있고, 외부 도구가 필요 없다.

### 3.1 기록 설정

```bash
python dataset_recorder.py --socket /tmp/surgitag/daq.sock \
    --rate 100 --decimate average --cutoff 5
```

거상력이 0.2 N 수준으로 작을 것으로 예상되므로(§3.3) **블록평균과 5 Hz 저역통과로 노이즈를 눌러야 한다.** 굽힘 축 노이즈 바닥이 ~0.1 N이라 평활 없이는 신호가 묻힌다. MCU 레코더를 함께 돌려 `grip`(홀센서 파지율)과 자세를 같이 남긴다.

### 3.2 파지 개시력

jaw가 충수를 무는 순간을 기록한다.

| 항목 | 설정 |
|---|---|
| 파지 지점 | 충수 원위 1/3, 매번 동일 (테이프 표식) |
| 동작 | 무접촉 → 접촉 → 완전 파지까지 **일정 속도로 1회** |
| 반복 | 시편당 n≥10 |
| 개시 시점 판정 | 홀센서 `grip` 상승 개시 (MCU 스트림) |

읽는 값:

| 지표 | 산정 | 의미 |
|---|---|---|
| `gripping` 상승 궤적 | 개시 → 완전 파지까지의 손잡이 힘 | handle actuation force. 절대값 주의 |
| 완전 파지 시 `gripping` | 정상상태 평균 | 〃 |
| 파지 중 `F_tip` 변화 | 개시 전 영점 대비 증분 | **비대칭 파지로 조직에 가해지는 횡력** |
| 개시 → 완전 파지 소요 시간 | `grip` 궤적 | 동작 속도 정규화용 |

> `gripping` 축은 분해능 0.5 N이고 굽힘·비틀림 오염이 있다. 파지 개시 구간은 아직 거상 전이라 굽힘이 작으므로 **오염이 가장 적은 구간**이다 — 이 축을 쓰기에 상대적으로 유리한 조건이다. 그래도 절대값은 부록 A-1 이후에 확정한다.

### 3.3 충수 거상력

파지 상태에서 충수를 들어올린다. **충수를 자유롭게 매단 상태의 중력보다 큰 만큼이 부착 구조의 저항**이다 — 이게 이 측정의 스펙 가치다.

| 항목 | 설정 |
|---|---|
| 동작 | 파지 → 수직 거상 → **3초 유지** → 하강 |
| 거상 높이 | 단계별: 5 / 10 / 15 / 20 mm (베이스 기준, 지그 없이 시각 표식으로) |
| 반복 | 높이별 n≥5 |
| 읽는 값 | 유지 구간 마지막 1초의 `F_tip` 평균 |

해석:

```
F_거상(h) = F_중력 + F_부착저항(h)
```

- `F_중력`은 충수 질량 × g. 충수 체적 14.87 cm³, 실리콘 밀도 약 1.07 g/cm³ 가정 시 **약 16 g → 0.16 N** 수준
- 거상 높이가 올라갈수록 간막이 당겨지고 지지체 반력이 커지므로 `F_부착저항`이 증가한다. **힘–높이 곡선의 기울기가 부착 구조의 강성 대리지표**가 된다
- 질량 실측(전자저울)은 부록 A-3이지만, **곡선을 먼저 얻어 두면 질량만 나중에 넣어 분해**할 수 있다

> 거상 높이를 지그 없이 시각 표식으로 정하므로 높이 불확도가 크다(±2 mm 수준). 따라서 §3.3의 결과는 **힘–높이 추세**로 보고하고, 정밀한 N/mm는 부록 A-2로 미룬다. 추세 자체는 지금 측정 가치가 있다.

### 3.4 이동 중 힘

거상 상태에서 충수를 움직인다. 굽힘 x·y 두 평면이 있으므로 **방향별 힘 분포**를 낼 수 있다.

| 항목 | 설정 |
|---|---|
| 동작 | 거상 10 mm 유지 → 좌/우/전/후 각 방향으로 왕복 이동 → 복귀 |
| 이동 범위 | 방향별 약 20 mm (베이스 표식) |
| 속도 | 왕복 1회 약 2초, 일정하게 |
| 반복 | 방향별 n≥5 |

읽는 값:

| 지표 | 산정 |
|---|---|
| 힘 포락선 | 이동 전구간 `F_tip` 의 max / mean / p95 |
| **방향 분포** | `θ = atan2(bg_y, bg_x)` 의 극좌표 히스토그램 (`|F_tip| > 0.3 N` 구간만) |
| 방향별 최대력 | 좌/우/전/후 각각의 `F_tip` peak |
| 비등방성 | 최대 방향 / 최소 방향 힘 비 |

> 극좌표 히스토그램은 CDE 보고서 Figure D8이 이미 쓰는 표현이다 ([`CDE2026/CDE_2026_REPORT.md`](CDE2026/CDE_2026_REPORT.md) §7.4). **팬텀의 부착 구조가 방향에 따라 다르게 버틴다면 여기서 드러난다** — 간막이 한쪽에만 붙어 있고 지지체가 아래에만 있으므로 비등방성이 예상된다. 설계가 의도한 "3차원 거동"의 직접 증거가 된다.

### 3.5 Phase 1 출력 요약

세 측정이 하나의 연속 에피소드로 묶인다. 단계 경계는 `grip`(홀센서)과 `F_tip` 궤적으로 자동 분절할 수 있다.

```
[무접촉] → [파지 개시] → [거상] → [이동 × 4방향] → [하강] → [파지 해제]
            §3.2         §3.3      §3.4
```

## 4. Phase 2 — 그래스퍼 미끄러짐 임계력

팬텀 README §7이 "젤은 외관 처리가 아니라 역학적 설계"라고 주장하는 부분을 정량화한다. **비로 보고하므로 절대 N 미확정 상태에서도 완결되는 유일한 스펙**이다 — 우선순위가 가장 높다.

### 4.1 미끄러짐 판정을 `gripping`으로 하지 않는다

| 이유 | 상세 |
|---|---|
| 분해능 부족 | 0.5 N — 6축 중 가장 거칠다 |
| 굽힘 오염 | 굽힘 4.9 N에서 −1.07 ~ −1.20 N 가짜 출력 |
| 비틀림 오염 | 순수 비틀림 0.23 N·m에서 −1.57 N |
| 구간이 겹침 | 견인 중 미끄러짐은 굽힘·비틀림이 동시에 실린 상황 = 오염이 가장 사나운 구간 |

대신 **미끄러짐 시점은 `F_tip` 급락으로 판정**한다. 조직이 벗어나면 굽힘이 사라지므로 신호가 직접이고, 굽힘 축은 분해능 0.1 N에 R² 1.000이다.

**보고하는 값** = 급락 바로 전의 `F_tip` peak. "그 파지로 받아낼 수 있었던 장력의 한계"다.

### 4.2 설계

| 항목 | 설정 |
|---|---|
| 조건 | 젤 없음 / 젤 도포 두 조건 |
| 반복 | 조건당 n≥10 |
| 파지 지점 | 충수 원위 1/3, 매번 동일 (테이프 표식) |
| 파지율 | 홀센서 `grip` 값으로 고정 |
| 동작 | 파지 → 미끄러질 때까지 수직 견인 |
| 기록 | `--rate 1000 --decimate subsample --cutoff 0` |
| 비교 | 젤 없음 → 젤 도포 **분할비** |

> **절대값보다 비(ratio)로 보고하라.** 모멘트암 부정확성·오염·시편 변동이 젤 전후에 공통으로 들어가므로 비를 취하면 상쇄된다. "젤 도포 시 미끄러짐 임계력이 0.4배로 낮아진다"는 주장이 "3.2 N에서 미끄러졌다"보다 훨씬 강하고, **부록 A-1 없이도 게재 가능하다.**

### 4.3 젤 상태 통제 (도구 없이)

이 실험의 유일한 교란 요인이다. 초음파 젤은 시간이 지나면 마른다. 질량 계량(저울)은 부록 A-3이므로, 그 대신 공정을 고정한다.

- **동일 작업자가 동일 방식으로 도포**한다 (도포 범위를 표식으로 정하고, 주사기/스패츌러 왕복 횟수를 고정)
- 도포 후 **경과 시간을 고정**하고 기록한다 (예: 도포 60초 후 시작, 5분 이내 종료)
- 젤 없음 조건은 **같은 시편에서 도포 전에** 먼저 수행해 시편 변동을 없앤다
- 5분을 넘기면 **재도포**하고 그 사실을 기록한다

## 5. Phase 3 — 파단·분리력 (파괴)

Phase 1~2를 끝낸 시편으로 수행한다. 시편이 소모되므로 마지막이다.

### 5.1 기록 설정 — peak 보존

```bash
python dataset_recorder.py --socket /tmp/surgitag/daq.sock \
    --rate 1000 --decimate subsample --cutoff 0
```

기본값 `--rate 100 --decimate average`는 연속 10개 표본의 산술 평균을 1표본으로 만든다. 이 평활이 파단 peak를 깎아 과소평가를 낳는다 — 파단은 수 ms 짧은 이벤트다. 반대로 1000 Hz subsample은 그 평활이 주던 노이즈 저감(약 3.2배)을 포기하므로 노이즈 바닥이 ~0.3 N으로 오른다. 파단력은 N 단위 이상이니 바꿀 만한 거래다.

### 5.2 파단 부위는 선택할 수 없다 — 사후 분류로 설계한다

grasper 하나로 당기면 **가장 약한 고리가 끊어진다.** 충수를 파지해 당길 때 끊어질 수 있는 곳은 세 군데이고, 어디가 먼저 갈지는 당기기 전에 정할 수 없다.

```
          [간막]
            │  ← ③ 간막 파열 / 간막–충수 접합 분리
            │
 [맹장]═════╪═══════════[충수]━━━━▶ 견인
       ①    ②
  ① Sil-Poxy 충수–맹장 접합 분리
  ② 충수 기저부 자체 파단
  ③ 간막 계통 파열
```

따라서 "충수 기저부 파단력"과 "Sil-Poxy 충수–맹장 분리력"을 **따로 겨냥해 측정하는 것은 불가능**하다. 설계를 바꾼다 — **시행 1회 = 당기기 1회 → peak 기록 + 파단 부위 분류**.

| 하중 방식 | 읽는 값 | 사후 분류 | n |
|---|---|---|---|
| 충수 원위 1/3 파지 후 수직 견인 | `F_tip` peak | ① / ② / ③ / 미끄러짐 | ≥8 |
| 간막 부채살 자유연 파지 후 견인 | `F_tip` peak | 간막 파열 / 간막–충수 / 간막–맹장 / 미끄러짐 | ≥8 |

분류는 **영상 + 파단 후 육안 검사**로 한다(§5.5). 보고는 부위별로 층화한다.

| 보고 항목 | 산정 |
|---|---|
| 부위별 파단력 | 그 부위로 분류된 시행들의 mean ± SD, n |
| **최약 고리** | 가장 자주 먼저 끊어진 부위와 빈도 (예: ① 6/8) |
| 부위별 빈도 | ① / ② / ③ 비율 |

> **최약 고리 자체가 쓸 만한 스펙이다.** "이 팬텀은 견인 시 8회 중 6회가 Sil-Poxy 충수–맹장 접합에서 먼저 분리된다"는 문장은 팬텀의 파괴 거동을 그대로 서술하며, 수술 술기 훈련에서 무엇이 먼저 망가지는지를 알려준다. 부위를 겨냥할 수 없는 것이 제약이지만, 층화 보고로 바꾸면 손실이 아니다. n을 5에서 8로 올린 이유도 이것이다 — 부위별로 나뉘면 셀당 표본이 줄어든다.

### 5.3 미끄러짐으로 끝난 시행 — 중도절단 처리

grasper 하나로는 **파단보다 미끄러짐이 먼저 올 수 있다.** 충수 직경 13~14 mm에 젤까지 있으면 가능성이 높다. 이 시행을 버리면 파단력이 과대추정되므로 중도절단(censored) 자료로 다룬다.

| 결과 | 처리 |
|---|---|
| 파단 발생 | 관측값. `F_tip` peak = 그 부위의 파단력 |
| 미끄러짐으로 종료 | **중도절단.** 그 시편의 파단력 > 기록된 peak (하한값) |

- 전 시행이 미끄러짐으로 끝나면 보고는 **"파단력 > (미끄러짐 임계력 최대값)"** 하한으로 쓴다. 이것도 유효한 결과다
- 미끄러짐을 줄이려면 **젤 없음 조건**에서, 파지율을 최대로, 파지면이 충수 장축에 수직이 되게 문다
- 중도절단 비율을 반드시 함께 보고한다 (예: 8회 중 3회 중도절단)

> 이 한계는 기구 구성에서 오는 것이고 팬텀의 결함이 아니다. Methods에 **"파단력은 단일 grasper 견인으로 측정했고, jaw 미끄러짐이 상한을 준다"** 고 명시하면 심사자가 수긍한다. 숨기면 표본 수가 줄어든 이유를 설명할 수 없게 된다.

### 5.4 견인 속도 보고

§8.4가 "등속 견인"을 요구하는데, **사람 손으로는 등속이 되지 않는다.** 외부 장비 없이 쓸 수 있는 방법은 하나다.

`F_tip` 시계열에서 **파단 전 0.5 s 구간의 dF/dt 중앙값**을 같이 싣는다. 실리콘은 점탄성체라 파단력에 속도 의존성이 있으므로, **속도 구간을 명시하지 않은 파단력은 재현 불가능한 수치다.**

> 추 + 도르래 램프로 등속에 가깝게 만드는 방법은 부록 A-4. 더 재현성이 높지만 교정추·도르래가 필요하다.

### 5.5 파단 부위 분류와 시점 교차확인

**영상이 없으면 §5.2의 층화 보고가 성립하지 않는다.** 분류의 근거가 되므로 선택이 아니라 필수다.

카메라 레코더를 함께 돌린다 (260830에서 쓰던 그대로 — 리포 내 `Camera/` 계통이므로 외부 도구가 아니다). mp4 사이드카 h5의 `timestamp[i]`가 프레임별 절대시각이므로 힘 peak의 Unix epoch와 직접 맞춘다.

두 가지를 영상으로 판정한다.

1. **파단 vs 미끄러짐** — 힘 peak가 진짜 파단인지, jaw에서 빠져나간 것인지. Phase 2에서 미끄러짐의 `F_tip` 서명을 이미 확보해 두었으므로 대조가 쉽다. §5.3의 중도절단 판정이 여기서 나온다
2. **파단 부위 ① / ② / ③** — 어느 고리가 먼저 끊어졌는지

영상으로 애매한 경우 **파단 후 육안 검사**로 확정한다 — 접합면이 깨끗하게 떨어졌으면 Sil-Poxy 분리(①), 실리콘이 찢어졌으면 조직 파단(②). 판정 결과를 시행별로 기록해 둔다.

### 5.6 주의

충수·간막은 소모성이므로 **n≥8은 주조 8회를 의미한다.** 로트 간 변동이 시편 변동에 섞이니, 가능하면 **한 배치에서 여러 시편을 동시 주조**하고 배치 번호를 기록한다.

Phase 1~2를 거친 시편이므로 **선행 조작의 피로 누적**이 있다. 조작 반복 횟수를 시편별로 기록해 파단력과의 상관을 사후 점검한다. 상관이 보이면 Methods에 한계로 쓴다.

## 6. Phase 4 — 수행 지표

Phase 1~3은 팬텀의 스펙을 낸다. Phase 4는 그 팬텀 위에서 사람을 재는 단계다. **Phase 3이 먼저 끝나야 한다** — 과도력 임계값을 파단력에서 가지고 와야 하기 때문이다.

### 6.1 과제 정의 — grasper 단독으로 가능한 것만

기구가 grasper 하나뿐이므로 **절단·결찰이 들어가는 과제는 수행할 수 없다.** 충수절제술 전체 술기(간막 박리 → 기저부 결찰 → 적출)를 과제로 삼을 수 없고, 대항견인도 불가능하다. 파지·견인 계열로 과제를 좁힌다.

| 과제 | 내용 | 성격 |
|---|---|---|
| T1 파지 정확도 | 지정 지점(표식)을 1회에 파지 | 재파지 횟수가 지표 |
| T2 거상 유지 | 충수를 10 mm 들어 10초 유지 | 힘 안정성 |
| T3 방향 견인 | 지정 방향으로 20 mm 견인 후 복귀, 4방향 | 방향별 제어 |
| T4 미끄러짐 회피 | 미끄러지지 않고 최대 장력까지 견인 | Phase 2 임계력 대비 비율 |
| T5 조직 보호 견인 | 과도력 임계값을 넘지 않고 T3 수행 | 임계값 준수율 |

> 과제가 술기 전체가 아니라 파지·견인으로 한정되므로, 논문에서는 **"grasping and retraction task"** 로 명확히 쓴다. "appendectomy task"라고 쓰면 과장이다. 대항견인 없는 단일 기구 조건도 명시한다 — 실제 복강경 술기와 다른 점이고, 심사자가 묻는다.

### 6.2 지표 정의

| 지표 | 산정 | 주의 |
|---|---|---|
| 최대·평균 장력 | `F_tip` peak, mean | — |
| Impulse | `∫F_tip dt` 에피소드 전구간 | 지속시간으로 나눠 정규화한 값도 같이 보고 |
| 과도력 이벤트 수 | `F_tip` > 임계값 구간 수 | 임계값 = **Phase 3 파단력의 50%** |
| 평활도 | `dF/dt` RMS 또는 변동계수 | 100 Hz average 기준으로 통일 |
| 파지 지속 비율 | `grip` > 역치인 시간 / 전수 | MCU 홀센서 스트림 |
| 거상·이동 힘 효율 | Phase 1 기준값 대비 비율 | **Phase 1이 사람 평가의 기준선이 된다** |
| 재파지 횟수 | `grip` 하강→상승 사이클 수 | T1·T4. 미끄러짐이 곧 재파지다 |
| 미끄러짐 여유율 | 최대 `F_tip` / Phase 2 임계력 | T4. 1에 가까우면 한계까지 쓴 것 |
| 과제별 분리 | T1~T5 구간 라벨 | 영상 time-sync |
| 조직 손상 | 파열·열상 유무 | 이진, 영상 판정 |

> **임계값은 이 팬텀의 파단력에서 나와야 한다.** 문헌의 장 조직 손상 역치를 인용하는 것은 팬텀이 그 범위를 재현하는지 선행 증명해야 유효하고, 동일 재현은 Shore 10 실리콘에서 원리적으로 어렵다. 자기 팬텀 파단력의 50%로 정의하면 순환 없는 기준이 된다.

### 6.3 기록 설정

```bash
python dataset_recorder.py --rate 100 --decimate average \
    --cutoff 0 --dataset <피험자ID>
```

MCU 레코더·카메라 레코더를 동시에 돌린다. 세 레코더가 같은 Unix epoch를 찍으므로 나중에 `timestamp` 하나로 병합된다 — 260830에서 이미 증명된 경로다.

### 6.4 Construct validity

숙련자 vs 초심자 힘 서명 비교. 팬텀 README §8.6의 예상 방향을 그대로 사용한다.

| 지표 | 예상 |
|---|---|
| 최대 장력 | 초심자 ↑ |
| Impulse | 초심자 ↑ |
| 평활도 | 숙련자 ↑ |
| 과도력 이벤트 | 초심자 ↑ |
| 거상·이동 힘 (Phase 1 대비) | 초심자 ↑ |

표본 수는 §8.7 기준으로 **피험자 n≥10**. 시간만 본 연구는 많지만 힘까지 본 연구는 드물므로 기여가 여기 있다.

### 6.5 주의 — 장력 절대값은 피험자 간 비교하지 않는다

수행 지표는 **동일 세션의 동일 접촉점에서만** 절대 비교가 유효하다. 피험자마다 기구를 쥐는 위치가 다르면 모멘트암이 달라지므로, 기구 파지 지점에 테이프로 표식해 고정한다. 이게 어려우면 **피험자당 정규화**(본인 최대값 대비 비율)로 바꿔 보고한다.

## 7. 기록 설정 요약과 선결 과제

### 7.1 Phase별 녹화 설정

| Phase | `--rate` | `--decimate` | `--cutoff` | 읽는 축 |
|---|---|---|---|---|
| 1 조작 힘 | 100 | average | **5** | `F_tip`, θ, `gripping`, `grip` |
| 2 미끄러짐 | **1000** | **subsample** | 0 | `F_tip` |

| 4 수행 지표 | 100 | average | 0 | 전 6축 |

Phase 1만 `--cutoff 5`를 쓴다.

### 7.2 실행 도구

프로토콜 전 단계를 **하나의 연속 녹화**로 수집하는 GUI 가 리포에 있다.

| 파일 | 역할 |
|---|---|
| [`phantom_experiment.py`](phantom_experiment.py) | 단계·시행 라벨을 붙여 h5 + 시행 CSV 를 남기는 실험 GUI |
| [`run_phantom_experiment.sh`](run_phantom_experiment.sh) | 실행 래퍼 (드라이버 소켓 자동 연결) |

```bash
# 터미널 1 — 드라이버 (RT 커널이므로 realtime 폴더)
cd linux_daqmxbase_realtime && ./run_driver.sh --device Dev1 --channels 8 --rate 1000

# 터미널 2 — Phase 1 (조작 힘)
./run_phantom_experiment.sh --specimen A01 --rate 100 --cutoff 5

# 터미널 2 — Phase 2~3 (미끄러짐·파단, peak 보존)
./run_phantom_experiment.sh --specimen A01 --rate 1000 --decimate subsample --cutoff 0
```

조작키: `[space]` 시행 시작/종료 · `[n]`/`[b]` 단계 이동 · `[r]` 녹화 · `[c]` 영점 ·
`[1..4]` 마지막 시행 파단 부위 분류 · `[u]` 시행 취소 · `[q]` 종료.

h5 에 `stage`(단계 코드)와 `trial`(시행 번호) 두 라벨 채널이 샘플마다 붙으므로 사후
분석에서 구간을 자동으로 갈라낼 수 있다. 시행이 끝날 때마다 CSV 에 peak / mean / p95 /
peak 시점 방향 θ / 파단 전 dF/dt / 급락비가 한 줄로 적힌다 — §8.1 표의 입력이 그대로 된다.

> `calib_phantom.json` 이 있으면 자동으로 그것을 쓰고, 없으면 `calib.json` 으로 떨어지면서
> **"상대값으로만 쓸 것"** 경고를 띄운다 (§2.2).
 거상력이 노이즈 바닥에 가까워 평활이 필요하고, 준정적 동작이라 peak 보존이 필요 없다.

### 7.3 세션 전 검증 (도구 없이, 2분)

기지 하중 선형성 검증은 외부 기준기가 필요하므로 부록 A-1로 미룬다. 지금 할 수 있는 것만 남긴다.

- [ ] 무부하 중립 자세에서 `c` 영점(tare)
- [ ] 무부하 60초 유지 → **드리프트 (N/min)** 기록
- [ ] 기구 자세를 크게 바꾼 뒤 다시 영점 → 자세 의존 오프셋 기록
- [ ] 파지 지점·접촉점 테이프 표식이 전 세션과 동일한지 확인
- [ ] 주변 온도를 기록 (온도계가 있으면)

### 7.4 측정 전 선결 과제 (도구 불필요)

팬텀 보고서 §6.4가 미확정으로 적어둔 항목 중 **확인만으로 해소되는 것**이다.

- [ ] **Shore A 인가 Shore 00 인가** — 사용한 제품명을 확인해 명기. 둘은 서로 바꿔 읽을 수 없는 다른 경도 단위이므로, 이것이 정해지지 않으면 이중경도 주장 자체가 성립하지 않는다
- [ ] **충수 내부 공정 확정** — 통짜 주조인가 코어 충전인가. 몰드는 코어 플러그가 없는 2분할 통짜 설계(`AppendixMold_A`/`_B`)이므로, 통짜라면 팬텀 README §7에서 충수 이중경도 주장을 삭제
- [ ] **베이스 출력 상태 확정** — §6.2는 출력 완료로, §9.1은 256 mm 베드 초과·분할 미구현으로 적혀 있다
- [ ] **배치 기록 체계** — 시편마다 주조 배치 번호를 붙일 것. 사후에 로트 변동을 분리할 유일한 수단

### 7.5 재현성에 대한 정직한 보고

팬텀 README §6.1이 재현성을 이미 가르고 있는데, 그게 측정값 해석과 직접 연결된다.

| 구성 | 재현성 | 측정값에 미치는 영향 |
|---|---|---|
| 충수·맹장 | 높음 (몰드 결정) | Phase 1·3 수치가 로트 간 일관 — **스펙으로 보고 가능** |
| 지지체 3개 | 낮음 (수작업) | 거상·이동 반력과 견인 반력을 지지체가 결정 → **Phase 1·3 산포에 직접 연결** |
| 간막 | 중간 | 두께 0.5 mm가 목표값 → 파열력·방향 비등방성 산포 클 것으로 예상 |
| 젤 | 낮음 | Phase 2는 이 산포를 **비로 상쇄** |

논문에는 재현성 높은 구성(충수·맹장)의 스펙을 주로 내세우고, 지지체·간막·젤은 **공차와 함께 제한사항에 쓰는 것**이 방어하기 안전하다. 지지체를 지그화해 재현성을 올리는 것도 다음 버전 개선 항목으로 제시할 수 있다.

### 8.2 Methods 필수 기재 사항

자작 센서로 얻은 수치라 심사자가 반드시 집는 지점들이다. 하나도 빼지 말 것.

1. **센서 구성** — 선형 게이지 8 (half-bridge 4) + 로제트 1 + 손잡이 1, USB-6009 1000 Hz. 축방향 채널과 변위 채널이 없다는 사실을 명시
2. **기구 구성 — 계측 grasper 1개** — 게이지가 부착된 복강경 툴이 grasper 하나뿐이라 (a) 모든 힘을 파지 후 견인으로 가했고, (b) **대항견인 없는 단일 기구 조건**이며, (c) 절단·결찰이 들어가는 과제는 수행하지 않았고, (d) **파단 부위를 겨냥하지 못해 사후 분류했다**는 네 가지를 명시. jaw 개구 폭과 충수 직경(14.0 × 12.3 mm)의 비도 기록 — 파지 안정성의 1차 결정 인자다
3. **파단력의 상한이 jaw 미끄러짐** — 중도절단 비율과 그 처리를 명시(§5.3). 전 시행이 미끄러짐이면 하한값으로 보고했다는 사실까지
4. **캘리브레이션 상태** — 사용한 행렬의 출처와 하중 지점. 접촉점 재캘리브레이션을 수행했는지(A-1), 하지 않았다면 **어떤 값이 상대값인지 표에 명시**. [`CALIBRATION_REPORT.md`](CALIBRATION_REPORT.md) §5.3 / §3 형식으로 디커플링 행렬과 교차누설표를 실을 것
5. **거상 높이·이동 범위의 부여 방식** — 시각 표식이며 지그가 아니라는 점, 불확도 추정치(±2 mm 수준)
6. **견인 속도** — 파단 전 0.5 s 구간 dF/dt 중앙값. 실리콘은 점탄성이라 속도 없는 파단력은 재현 불가
7. **파지력은 handle actuation force** — jaw-tissue force가 아니다. 게이지가 손잡이에 있어서이고, 링크 전달비·마찰을 보정하지 않았다고 쓸 것. `F_tip`에 잡히는 것은 비대칭 파지로 생기는 횡력이라는 점도
8. **측정 순서** — 같은 시편에서 비파괴 → 파괴 순으로 수행했다는 사실. 선행 조작이 파단력에 영향을 줄 수 있으므로(피로) 반복 횟수를 함께 보고
9. **as-built가 설계와 다른 부분** — 팬텀 README §6.1 표를 거의 그대로. 지지체 3개 전용과 소장 1개 구성은 생략하면 재현 불가
10. **제한사항** — 지지체·간막·젤의 재현성 낮은 점, 충수가 통짜라면 그 사실, 임계값이 자기준인 점, 강성 계열 미측정

### 8.3 이 팬텀의 더 큰 용도 — CDE 한계 ②

[`CDE2026/CDE_2026_REPORT.md`](CDE2026/CDE_2026_REPORT.md) §10이 다음을 미완으로 남기고 있다.

> ② **독립 팁 힘 기준** ⚠️ 미완 — "조직 접촉력"의 기준이 원위 게이지 자신 / 팁에 외부 기준 힘센서를 달고 재실험

팬텀은 이걸 닫는 재료가 된다. **파단력·강성이 한번 고정되면, 그 이후에는 같은 팬텀을 기구로 조작했을 때 `F_tip`이 그 알려진 값을 복원하는지 검증할 수 있다.** 팬텀을 훈련 모델로만 쓰는 것보다 기여가 크고, 추가 장비가 필요 없는 방향이다.

다만 주의 — 팬텀 힘을 **같은 게이지로** 재고 그걸로 같은 게이지를 검증하면 순환이 된다. 팬텀 스펙이 독립 기준이 되려면 **센서 밖 기준으로 한 번은 대조**해 두어야 한다. 그것이 부록 A-1이다.

## 9. 부록 A — 보류 항목 (외부 도구 필요)

SurgiLogger만으로는 수행할 수 없어 본문에서 제외한 항목이다. 필요한 도구와 그것이 무엇을 풀어주는지만 남긴다.

| # | 항목 | 필요 도구 | 풀리는 것 |
|---|---|---|---|
| **A-1** | 접촉점 재캘리브레이션 | 푸시형 저울 또는 교정추 + 도르래 | **본문 전체의 절대 N**. jaw 끝에서 샤프트 수직으로 기지 하중을 6단계 이상 가해 [`calibrate.py`](calibrate.py)로 재적합. 세션 전 선형성·이력 검증도 함께 가능 |
| **A-2** | 강성·이중경도 전이점 | 기계가공 심(±0.01 mm) 또는 마이크로미터 + 1축 거치 지그 | 맹장 압입 강성, 충수 굽힘 강성, 이중경도 전이점 (N/mm, mm). 변위를 센서로 재지 않고 **심 두께로 부여**하는 방식 |
| **A-3** | 질량·치수·벽 두께 실측 | 전자저울, 디지털 캘리퍼, 듀로미터 | 거상력에서 **중력과 부착저항을 분리**(§3.3), 전이점 해석의 기준이 되는 실측 벽 두께, 젤 도포량 정량화 |
| **A-4** | 등속 견인 | 교정추 + 도르래 | 파단력의 속도 통제. 현재는 사후 dF/dt 보고로 대체(§5.3) |

### A-1이 우선순위 1위인 이유

A-1만 있으면 본문에서 측정한 **모든 상대값이 절대값으로 환산된다.** 측정을 다시 할 필요가 없다 — h5에 원전압 `raw`가 함께 저장되므로 새 행렬로 재계산하면 된다. 필요한 것은 푸시형 저울 하나(주방·택배용, g 표시)와 테이프·자 뿐이다.

A-2는 지그 제작이 필요해 리드타임이 길고, 측정 항목이 독립적이므로 나중에 붙여도 논문 구조가 흔들리지 않는다.
